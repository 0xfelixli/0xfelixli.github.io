# Gallery Photos

Put travel photos for the Gallery page in this folder.

For each photo, create a Markdown file in `data/gallery/`.

Example:

```md
---
title: Kyoto Rain
place: Kyoto
date: 2026
image: /gallery/kyoto-rain.jpg
alt: Kyoto street after rain
featured: false
order: 10
---

雨后的街道很安静，光线刚好落在屋檐下面。
```
